# PROMPTS — плейбук «довести сайт до ума»

Готовые промты для будущих сессий Claude Code. Открываешь задачу → копируешь блок `📋 ПРОМТ` → вставляешь в новую сессию → следуешь визуальной итерации.

> Сайт структурно готов (11 маршрутов, 22 секции, дизайн-система). Здесь — что осталось довести до запуска и красоты. Приоритет задач — **баланс**: запуск-критичное и дизайн вперемешку.

---

## Как пользоваться

1. Открой папку проекта в Claude Code — `STATUS.md`, `CLAUDE.md`, `brand-kit.md` подгрузятся в контекст автоматически.
2. Выбери задачу ниже по номеру. Делай по порядку (порядок сбалансирован) или бери любую — каждая самодостаточна.
3. Скопируй её `📋 ПРОМТ` и вставь в сессию.
4. Дев-сервер для проверки: из папки `site/` → `npm run dev` → http://localhost:3000
5. После правок смотри на результат глазами через **chrome-devtools** (скриншот) и сверяй с чек-листом из `brand-kit.md §12`.

⚠️ Если новые MCP не отвечают (`/ui`, скриншоты) — перезапусти Claude Code: MCP-серверы грузятся при старте.

## Памятка по тулингу (что когда срабатывает)

| Инструмент | Как вызвать | Когда использовать |
|-----------|-------------|--------------------|
| **frontend-design** (скилл) | «используй frontend-design» или просто проси строить UI | Перед любой вёрсткой секции — задаёт осознанный дизайн вместо «generic AI» |
| **ui-ux-pro-max** (скилл) | «прогони через ui-ux-pro-max» | Выбор стиля/раскладки/палитры, дизайн-система, пред-релизный аудит UI |
| **Magic MCP** | `/ui <описание>` | Быстрый каркас типового блока (hero/pricing/testimonials), потом переписать под наш паттерн |
| **chrome-devtools** (MCP) | «сделай скриншот localhost:3000», «проверь консоль» | Видеть рендер, ловить ошибки, замер LCP, визуальная итерация, адаптив |
| **context7** (MCP) | добавь `use context7` в промт | Любой код под Next 16 / React 19 / Tailwind 4 (роутинг, формы, кэш, метаданные) |
| **figma** (MCP) | вставь ссылку на фрейм | Вёрстка по готовому макету из Figma |

**Жёсткие правила бренда (из `CLAUDE.md` и `brand-kit.md`) — соблюдать всегда:**
зелёный `#1A4731` + золото `#F5A623` на крем-фоне `#FAFAF7`, текст `ink #1C1C1E` (не чистый чёрный); шрифты только Manrope (заголовки) + Inter (текст); **без синего, без фиолетовых градиентов, без восклицаний в заголовках, без стоковых «бизнесменов»**; токены из `globals.css` (`@theme`), не хардкодить hex; текст правим в `src/content/*.ts`, не в JSX; UI-примитивы из `@/components/ui` (`cva`+Radix), shadcn CLI не используем.
